# 📩 Spam Message Classifier

An end-to-end Machine Learning application that classifies SMS/Email messages as **Spam** or **Ham (Normal)**.

The project demonstrates the complete ML application lifecycle:

- Data preprocessing
- Text cleaning
- TF-IDF feature extraction
- Machine Learning model training
- Model evaluation
- FastAPI REST API
- Automated testing with Pytest
- Docker containerization
- Git and GitHub
- GitHub Actions CI/CD
- GitHub Container Registry
- Cloud deployment using Render
- Public web frontend
